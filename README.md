# SEE HOME Landing Page

Landing page for SEE HOME built with Vite, React, TypeScript, and Tailwind CSS.

## Edit Content

Update the main website copy in `src/data/site.ts`.

- Change `phone` to the contact phone number used by the Call button.
- Change `zaloUrl` to the Zalo link used by the Zalo button.
- Edit headings, service copy, process steps, and project titles in the same file.

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Deploy on Vercel

Use Vercel with:

- Build command: `npm run build`
- Output directory: `dist`
